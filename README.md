# Real-Time Motion Detection System

## 📌 Overview
This project implements a real-time motion detection system using an MPU6050 accelerometer sensor and STM32 microcontroller.

## ⚙️ Technologies Used
- STM32 (Simulated using Wokwi)
- MPU6050 Sensor
- I2C Communication
- UART (Serial Output)

## 🔌 Hardware Connections

| MPU6050 | STM32 |
|--------|------|
| VCC    | 3.3V |
| GND    | GND  |
| SDA    | SDA  |
| SCL    | SCL  |

## 🧠 Features
- Reads accelerometer data (X, Y, Z)
- Detects motion using threshold
- Displays real-time data via Serial Monitor

## ▶️ Simulation (Wokwi)
Project simulated using Wokwi STM32 environment.
